# Roadmap

ODE is currently in its initial development phase.

## Phase 1 — Foundation

- Establish project structure
- Finalize contribution and governance processes
- Publish initial seed curriculum
- Define proposed Core curriculum
- Recruit initial practitioner reviewers and contributors
- Establish technical review standards

## Phase 2 — Core Curriculum

Develop and review the vendor neutral Detection Engineering Core.

Initial areas include:

1. Detection Engineering Foundations
2. Detection Requirements
3. Telemetry & Data
4. Detection Design
5. Detection Development
6. Testing & Validation
7. Detection-as-Code
8. Deployment, Tuning & Operations
9. Detection Health & Lifecycle
10. Detection Program Engineering

The final structure should be determined collaboratively by contributors.

## Phase 3 — Labs and Supporting Resources

- Reference labs
- Example datasets
- Exercises
- Instructor resources

## Phase 4 — Tracks

Begin community-led specialization tracks.

Potential tracks include:

### Domains

- Windows
- Linux
- AWS
- Azure
- GCP
- Identity
- Network

### Platforms

- Splunk
- Microsoft Sentinel
- Elastic
- CrowdStrike Falcon
- SentinelOne

### Advanced

- Detection Research
- AI-Assisted Detection Engineering

## Phase 5 — Mature Community

- Expand maintainer and reviewer groups
- Establish recurring curriculum review
- Publish versioned curriculum releases
- Develop partnerships with training providers, vendors, universities, and other organizations
- Evaluate formal nonprofit/community governance if project scale warrants it
