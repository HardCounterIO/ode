# Datasets

Open datasets for lessons, testing, labs, and exercises.

**Status:** none yet. To propose one, open a [Dataset Proposal](https://github.com/HardCounterIO/ode/issues/new/choose).

## Requirements

Each dataset is a directory containing:

- `README.md`: what it contains, how it was produced (provenance), format, size, and the malicious and benign activity a learner should be able to identify
- `LICENSE`: the dataset's own license ([LICENSE.md](../LICENSE.md#datasets))

Datasets must be synthetic, generated for ODE, or properly licensed. They must contain no real personal, customer, credential, or proprietary data, and example values follow the [Style Guide](../docs/STYLE-GUIDE.md#6-example-data-and-safety). See [SECURITY.md](../SECURITY.md#content-safety-rules) for what to do if sensitive data is committed by mistake.

## Review

A dataset review confirms provenance, licensing, the absence of real data, and that the described activity is actually present ([Review Process](../docs/REVIEW-PROCESS.md#9-labs-and-datasets)).
