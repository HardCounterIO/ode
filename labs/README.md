# Labs

Open reference labs that support ODE learning objectives. Organizations are also encouraged to build their own labs around the curriculum ([LICENSE.md](../LICENSE.md#using-ode-commercially)).

**Status:** none yet. To propose one, open a [Lab Proposal](https://github.com/HardCounterIO/ode/issues/new/choose).

## Licensing

- Written lab instructions are CC BY-SA 4.0.
- Lab tooling, scripts, and automation are Apache License 2.0.
- Third-party material must be identified and compatible ([LICENSE.md](../LICENSE.md#third-party-material)).

## Layout

Each lab is a directory containing a `README.md` that states:

- the learning objectives and the module or track it supports
- the environment and tooling required, and the deployment model
- the learner tasks
- the expected outcome, so a learner can tell they succeeded
- any datasets used (see [`datasets/`](../datasets/))

## Safety and Review

- No live malware or weaponized exploit code ([SECURITY.md](../SECURITY.md#content-safety-rules)).
- Never commit real credentials. Cloud labs use example variable files, not real ones.
- A lab is reviewed by someone other than the author completing it from the instructions in a clean environment ([Review Process](../docs/REVIEW-PROCESS.md#9-labs-and-datasets)).
