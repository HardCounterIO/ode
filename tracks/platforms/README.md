# Platform Tracks

Platform tracks cover Detection Engineering on specific products. They may go as deep on a product as needed, and they are where product-specific features belong (for example, Splunk-specific features that [Core](../../core/) avoids).

**Status:** none started.

Disclose any affiliation with the product you write about, and expect review by someone independent of the vendor. See [`tracks/README.md`](../README.md) for layout and expectations.
